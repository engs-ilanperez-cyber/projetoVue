# Lista de Tarefas com Vue.js

## Sobre o Projeto

Este é um aplicativo de lista de tarefas desenvolvido como trabalho da disciplina de Desenvolvimento Front-end. O projeto utiliza o framework Vue.js 3 para construir sua interface. Para iniciar o programa, clone o repositório, você deve abir o cmd, fazer cd com a pasta baixada e executar "npm run dev" e entrar no localhost apresentado.

## Funcionalidades


Adicionar novas tarefas
Marcar tarefas como concluídas
Remover tarefas
Filtrar por status
Contador de tarefas
Responsividade


### Pré-requisitos

- Node.js
- npm
